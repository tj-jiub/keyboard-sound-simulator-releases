# 키보드 음향 시뮬레이터 — 다운로드

Windows용 키보드 타건 소리 시뮬레이터의 공식 배포 저장소입니다.
앱 소스 코드는 비공개이며, 이 저장소는 설치 파일 배포와 자동 업데이트에만 사용됩니다.

## 다운로드

👉 **[최신 버전 받기](https://github.com/tj-jiub/keyboard-sound-simulator-releases/releases/latest)**

| 파일 | 용도 |
|---|---|
| `keyboard-sound-simulator-setup-*.exe` | 설치형 |
| `keyboard-sound-simulator-*.exe` | 포터블 (설치 없이 실행) |

- Windows 10/11 x64
- 코드 서명 전이라 첫 실행 시 SmartScreen 경고가 뜰 수 있어요 → "추가 정보 → 실행"
